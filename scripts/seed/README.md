# Synthetic data boundary

No production-derived database dump or anonymized runtime export is included. `demo/fixtures/sample-data.json` is a small, hand-authored example that is visibly fictitious.

If a richer demo seed is added later, build it from an explicit synthetic schema and review it independently for names, contact details, addresses, identifiers, free-text notes, document metadata, and media provenance. Do not use a customer database as the source.

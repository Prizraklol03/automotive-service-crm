# Security policy

This repository is a sanitized portfolio snapshot of a private commercial codebase. It contains no production configuration, customer records, operational runbooks, deployment credentials, or original Git history by design.

## Reporting a security issue

Please do not publish exploit details, suspected credentials, or privacy-sensitive findings in a public issue.

If the repository later enables GitHub private vulnerability reporting, use that channel. Until then, contact the repository owner privately through a contact method explicitly listed on the owner's GitHub profile and include only the minimum information needed to reproduce the problem.

## Scope and expectations

The snapshot is provided for code review and portfolio evaluation. It is not represented as production-ready, and it is not connected to a hosted service. Findings that reveal a missed production-specific artifact are especially important and should be reported privately.
